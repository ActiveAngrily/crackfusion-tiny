# Edge deployment, temporal/video, 3D, thermal, and multisensor crack evidence

**Scope.** Targeted primary-source survey of measured edge/TinyML deployment and non-RGB or temporally aggregated crack inspection. The project task is binary 224×224 RGB image classification; most papers below instead perform object detection, segmentation, point-cloud instance detection, or system-level inspection. Those are useful engineering precedents, not direct accuracy or latency baselines for this classifier.

**Search date/cutoff:** 6 October 2026. Searches were made on the date shown; only work published or available by that date is included. Search engines and publisher/arXiv/OpenReview pages were queried directly. This is a focused survey, not a systematic review.

Existing project survey notes an image-level split and no established device/energy protocol. |

For comparisons with this project, report parameters, MACs/FLOPs and model bytes separately. Include input shape, counter convention, precision/calibration, device and runtime/compiler, batch, warm-up, synchronization, latency statistic, memory, and energy measurement boundary. Batch throughput and end-to-end pipeline speed must not be presented as batch-1 inference latency. Quantization reports also need crack recall/F1 on identical held-out examples to show any quality loss. The present literature does not supply a common device/protocol on which to rank the listed rates.

| Primary source | Task and result | Fit and limits |
|---|---|---|
| Chen, Jahanshahi, Wu & Joffe (2017), “A texture-Based Video Processing Methodology Using Bayesian Data Fusion for Autonomous Crack Detection on Metallic Surfaces,” *Computer-Aided Civil and Infrastructure Engineering* [primary article](https://doi.org/10.1111/mice.12256) | Aggregates local-binary-pattern/SVM evidence over inspection-video frames using Bayesian fusion. | “Translating Crack Detection Accuracy in Concrete Structures in Live Video Stream using Low Cost Mobile using Deep Learning YOLOv8 Model” (2025) [primary proceedings PDF](https://www.avestia.com/NewTech2025_Proceedings/files/paper/ICCEIA/ICCEIA_164.pdf) | Studies concrete crack detection in a live mobile video stream using YOLOv8. | Concrete/live-video system context. Only search-indexed PDF snippet was accessible in this pass; no verified frame rate, device, timing boundary, or temporal fusion metric is recorded here. Treat as a lead, not quantitative evidence. |
| Zhouxiang et al. (2023), video-level crack detection workflow with latency mechanism [primary paper PDF](https://hira.hope.ac.uk/id/eprint/4572/1/NPIC_HMIT_2023_Final_Paper_Zhouxiang_40988.pdf) | Describes video-level detection for long industrial inspection videos, using a latency mechanism to reduce false positives. | Relevant temporal aggregation concept but the application is internal structural inspection, not surface-image classification; PDF snippet in this pass gives insufficient verified numerical results. |

Temporal evidence is sparse relative to frame-based detection. Distinguish repeated-frame aggregation/tracking from a learned temporal model. A future video study should evaluate event-level recall, false alarms per unit time or inspected area, detection delay, and duplicate suppression alongside per-frame accuracy; do not infer these from a still-image benchmark.

## Thermal and other multisensor crack evidence

| Primary source | Task and result | Fit and limits |
|---|---|---|
| Jang et al. (2019), hybrid visible/IR/line-laser concrete inspection [primary article](https://doi.org/10.1177/1475921718821719) | Concrete crack identification from visible/infrared hybrid images, acquired by a spatial scanning system; claimed improved detectability and fewer false alarms on lab-scale specimens. | The most direct crack-specific multimodal precedent located. Modality alignment, special scanning hardware and laboratory scope differ from ordinary RGB image classification. |
| “Crack detection of masonry structure based on thermal and visible image fusion and semantic segmentation” (2023) [primary publisher record](https://www.sciencedirect.com/science/article/pii/S0926580523004739) | Visible and thermal imagery are fused for masonry crack detection/semantic segmentation. Publisher-indexed text confirms RGB, IR, fused, and modality-specific model comparisons. | Direct crack/masonry thermal-fusion lead. Publisher open failed in this pass, so quantitative results, exact registration and acquisition conditions were not verified. Not a classification deployment benchmark. |
| Katual et al. (2023), multimodal visual/thermal inspection [primary paper PDF](https://deepjoining.github.io/papers/JLA2023.pdf) | Search-indexed paper text describes independent visible-image crack detection and thermal-image moisture classification with late decision fusion. | Multisensor structural-inspection evidence, but thermal branch targets moisture rather than crack pixels. Treat the crack/thermal combination as adjacent system architecture, not evidence that thermal improves crack detection. Full-text PDF indexed; only relevant snippet reviewed. |

Thermal and depth channels address different failure modes: thermal contrast can reveal subsurface/moisture-related anomalies or help under lighting variation; depth/laser gives geometry and scale. They add sensor cost, calibration/registration and domain-specific acquisition. RGB-only benchmark gains cannot be inferred from these systems. In the paper, position these as future inspection modalities unless the experiment actually includes aligned measurements.
