# CNN–Transformer vision architectures and foundations

**Survey date:** 6 October 2026\
**Question:** What do general-purpose vision backbones teach us about a compact, data-limited CNN–Transformer classifier for concrete cracks?\
**Boundary:** This is an architecture/foundation workstream. ImageNet, COCO, mobile-latency, and other general-vision results are reported only as the originating papers' evidence; none is evidence of crack-classification performance.

## Project context

The repository implements CrackFusion-Tiny in [`src/crackfusion_tiny.py`](../../../notebooks/03_crackfusion_train.ipynb): a shared CNN stem maps 224×224 RGB input to a 28×28×64 tensor; a depthwise-separable local path and a stride-2 token projection run in parallel; the latter produces 196 tokens of width 96 and passes them through two four-head Transformer encoder layers; tokens are reshaped to 14×14, concatenated with the local map, projected by a 1×1 convolution, and pooled to one logit. The code's parameter count is 284,337. It is custom and currently has no pretrained weights. The maintained MobileViT-XS baseline is an ImageNet-1K-pretrained, staged hybrid and replaces its classifier; see [the MobileViT comparison](../mobilevit_baseline_and_crackfusion_comparison.md).

The [existing literature synthesis](scope_existing_literature_synthesis.md) identifies local inductive bias, reduced token counts, explicit feature fusion, source-photo leakage, and matched ablations as the main design issues. This note adds a paper-by-paper architecture map and later compact-backbone checks.

## Search and reading record

Searches were run on 6 October 2026 using primary-paper queries for CNN–Transformer vision models, then citation/title searches for 2024–2026 compact mobile hybrids. Search targets included OpenReview, CVF Open Access, PMLR, ICLR proceedings, arXiv, ECCV proceedings, and the authors' official project pages. Titles were screened for general image-classification backbone relevance, then model topology, training/data claims, deployment measurement, and public code were checked against the linked paper/proceedings or author record. The prior Zotero snapshot and the two cited project literature files were used as coverage cross-checks.

**Access limit:** some CVF direct PDF opens returned HTTP 403 in this research interface. Their official CVF proceedings pages and bibliographic records remained accessible; where primary full text was accessible through arXiv, proceedings PDF, or author-hosted full text, that version was used. The search is a targeted narrative survey, not a database-registered systematic review; “read everything” cannot mean every paper ever published. Inclusion and access limits are recorded here rather than treating the screened set as exhaustive.

## Architecture patterns and trade-offs

1. **Local bias is useful before global reasoning.** ResNet's convolutional hierarchy and the convolutional tokenizers/blocks of CvT, CMT, MobileViT and MobileNetV4 encode locality and reduce spatial resolution. For narrow cracks, local gradients, edges and texture continuity are plausible cues; this is a motivation, not proof that convolution wins on SDNET.
2. **Global attention becomes affordable after downsampling.** ViT makes unrestricted relationships explicit but has quadratic token interactions. Swin restricts attention to shifting windows; CoAtNet delays attention to later stages; MobileViT/CvT/CMT tokenize lower-resolution feature maps. CrackFusion uses 196 tokens, for which standard MHSA is tractable; more exotic linear or grouped attention requires an empirical reason.
3. **Fusion topology is a meaningful independent variable.** Conformer and Mobile-Former exchange information repeatedly; MobileViT mixes serially within repeated blocks; CoAtNet/CMT interleave operators by stage; CrackFusion maintains two post-stem branches and joins once. These are different designs, and benchmark outcomes cannot establish which is better for crack classification.
4. **Latency is hardware- and implementation-dependent.** FastViT, EfficientViT, MobileNetV4, SHViT and TinyNeXt motivate reporting actual latency, memory, input resolution, batch, warm-up, runtime, and device. Parameter/MAC counts alone are incomplete because reshape, normalization, pointwise ops, and memory traffic can dominate.
5. **Small-data claims require separating initialization from structure.** Original ViT results lean on large-scale pretraining; DeiT demonstrates a recipe with strong augmentation and teacher distillation; mobile hybrids commonly provide ImageNet weights. SDNET's 56k crops descend from 230 photographs, so independent sample size is not crop count. Group splits and repeated seeds are more important than the headline count.

## Transferable guidance for this paper

- Retain ResNet-18 as an external, pretrained CNN reference and MobileViT-XS as the established pretrained hybrid. State clearly that scratch CrackFusion versus pretrained backbones is a practical model comparison, not an architecture-only causal test.
- To test the architecture claim, compare the same stem/training/data protocol with a local-only branch, attention-only branch, and the parallel fused model. Keep input resolution, parameter count approximately matched where practical, and disclose remaining mismatch.
- The current 14×14 feature token grid is a reasonable compromise: early 28×28 features preserve local detail, while 196 tokens bound attention. Test the actual effect of the second Transformer block or attention removal instead of introducing a new attention mechanism by default.
- Preserve branch feature maps and run matched attribution/error inspection. Attention maps and Grad-CAM are diagnostics, not causal proof.
- Use source-photo-separated partitions and report per-surface held-out generalization, class-sensitive metrics, multi-seed variation, parameters, MACs, memory, and measured latency. No reported ImageNet top-1 or mobile speed result in these architecture papers is evidence for crack-domain accuracy.
- Position the contribution narrowly: a small explicit local/global layout evaluated under leak-resistant concrete-crack classification conditions. CNN–Transformer combination, parallel streams, and cross-feature interaction already have extensive general-vision precedent; crack-segmentation precedent is covered in the adjacent review file.
