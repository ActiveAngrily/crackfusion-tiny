# CNN–Transformer vision architectures and foundations

**Survey date:** 6 October 2026\
**Question:** What do general-purpose vision backbones teach us about a compact, data-limited CNN–Transformer classifier for concrete cracks?\
**Boundary:** ImageNet, COCO, and mobile-latency results below are the originating papers' general-vision evidence; they are not crack-classification results.

## Project context

[`src/crackfusion_tiny.py`](../../../notebooks/03_crackfusion_train.ipynb) implements a 284,337-parameter model: a shared CNN stem maps 224×224 input to a 28×28×64 tensor; a depthwise-separable local path and stride-2 token projection run in parallel; the latter produces 196 tokens of width 96 and applies two four-head Transformer encoder layers; the Transformer map is reshaped to 14×14, concatenated with the local map, projected by a 1×1 convolution, and pooled to one logit. It has no pretrained weights. The maintained MobileViT-XS baseline is an ImageNet-1K-pretrained staged hybrid; see [`Literature Review/01_mobilevit_baseline_and_crackfusion_comparison.md`](../mobilevit_baseline_and_crackfusion_comparison.md).

The prior synthesis ([`00_existing_literature_synthesis.md`](scope_existing_literature_synthesis.md)) already identifies local inductive bias, reduced token counts, explicit fusion, source-photo leakage, and matched ablations as central concerns. This note maps the architecture precedents and extends coverage to 2024–2025 compact models.

## Paper evidence table

| Work / primary source | Topology and local/global mechanism | Efficiency, data, and pretraining caveats | Transferable lesson |
|---|---|---|---|
| **ResNet** — He et al., CVPR 2016, [paper](https://openaccess.thecvf.com/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html), [DOI](https://doi.org/10.1109/CVPR.2016.90) | Hierarchical convolutional stages with identity shortcuts; no attention or separate global stream. Receptive field grows through depth and downsampling. | ImageNet pretraining makes ResNet-18 a useful transfer reference; depth and width set its cost. | Keep ResNet-18 as a familiar CNN baseline. Scratch-versus-pretrained comparisons conflate initialization and topology unless stated clearly. |
| **ViT** — Dosovitskiy et al., ICLR 2021, [OpenReview](https://openreview.net/forum?id=YicbFdNTTy), [arXiv](https://arxiv.org/abs/2010.11929) | Patchify image, linearly embed patches, add positional/class tokens, then use global self-attention. The canonical model has no convolutional local path. | Strong results rely on large-scale pretraining; attention interaction cost grows quadratically with token count. This does not establish scratch ViT data efficiency on a few thousand independent source photographs. | Tokenize a reduced CNN feature map rather than raw pixels; match initialization when using a Transformer-only ablation. |
| **DeiT** — Touvron et al., ICML 2021, [PMLR paper](https://proceedings.mlr.press/v139/touvron21a.html), [arXiv](https://arxiv.org/abs/2012.12877) | ViT trained with stronger augmentation/regularization. A distillation token learns from teacher outputs, including a CNN teacher; this is supervision transfer, not CNN/Transformer feature-map fusion. | ImageNet-1K training is made competitive through extensive augmentation, long training and optional teacher distillation. Recipe matters alongside architecture. | If scratch attention underperforms, inspect training and initialization before rejecting attention. Use only crack-preserving augmentation; do not claim architecture effects from unmatched recipes. |
| **Swin Transformer** — Liu et al., ICCV 2021, [CVF proceedings](https://openaccess.thecvf.com/content/ICCV2021/html/Liu_Swin_Transformer_Hierarchical_Vision_Transformer_Using_Shifted_Windows_ICCV_2021_paper.html), [arXiv](https://arxiv.org/abs/2103.14030) | Hierarchical patch merging forms a feature pyramid; attention is local to windows, with alternating shifted windows connecting adjacent partitions. Hierarchical Transformer, not a two-branch CNN–Transformer. | Window restriction reduces high-resolution attention cost; shifting/partitioning has memory and implementation costs. Typical results use ImageNet pretraining. | Relevant if multi-scale or dense prediction becomes central. For 196 tokens, standard attention is tractable and simpler for an interpretable ablation. |
| **CvT** — Wu et al., ICCV 2021, [CVF proceedings](https://openaccess.thecvf.com/content/ICCV2021/html/Wu_CvT_Introducing_Convolutions_to_Vision_Transformers_ICCV_2021_paper.html), [arXiv](https://arxiv.org/abs/2103.15808) | Hierarchical stages use overlapping convolutional token embedding and convolutional Q/K/V projections to inject locality and positional structure into attention. | Progressive spatial reduction controls attention cost; reported benchmarks are general-image results, not crack evidence. | Convolutional tokenization and overlapping receptive fields are plausible for thin crack continuity; this supports a CNN stem but not necessarily a separate local branch. |
| **Conformer** — Peng et al., ICCV 2021, [CVF proceedings](https://openaccess.thecvf.com/content/ICCV2021/html/Peng_Conformer_Local_Features_Coupling_Global_Representations_for_Visual_Recognition_ICCV_2021_paper.html), [arXiv](https://arxiv.org/abs/2105.03889) | Concurrent CNN and Transformer streams preserve local maps and global tokens. Feature Coupling Units resample and exchange information across resolutions repeatedly; branch heads can contribute to prediction. | Repeated coupling adds operators/compute; results concern general recognition/detection and commonly use pretrained-scale training. | Strong precedent for inspectable branches and interaction. CrackFusion's single late join is simpler; neither parallel branches nor their fusion are novel by themselves. |
| **CoAtNet** — Dai et al., NeurIPS 2021, [paper](https://proceedings.neurips.cc/paper/2021/hash/20568692db622456cc42a2e853ca21f8-Abstract.html), [arXiv](https://arxiv.org/abs/2106.04803) | Sequential stages combine depthwise MBConv blocks with relative-attention Transformer blocks; convolution is generally earlier and attention later, rather than two persistent parallel streams. | Hierarchy and delayed attention control cost. Data-scaling claims span large training regimes and do not guarantee performance on a small crack dataset. | Compare late serial attention to the proposed parallel branch if the paper wants to isolate whether branch topology matters. |
| **CMT** — Guo et al., CVPR 2022, [CVF paper](https://openaccess.thecvf.com/content/CVPR2022/html/Guo_CMT_Convolutional_Neural_Networks_Meet_Vision_Transformers_CVPR_2022_paper.html), [arXiv](https://arxiv.org/abs/2107.06263) | Pyramid of blocks with depthwise-convolution local perception, lightweight MHSA for long-range context, and inverted-residual FFN with depthwise convolution. | Stagewise downsampling and local perception reduce cost versus flat global attention. Published evidence is ImageNet-oriented. | Depthwise spatial mixing can complement attention cheaply; attention need not run at full resolution. The added block complexity is unnecessary for a minimal fusion test. |
| **MobileViT / XS** — Mehta & Rastegari, ICLR 2022, [OpenReview](https://openreview.net/forum?id=vh-0sUt8HlG), [Apple research](https://machinelearning.apple.com/research/vision-transformer), [official code](https://github.com/apple/ml-cvnets) | Mobile CNN stages contain blocks that convolve locally, unfold feature maps into spatially arranged tokens, apply Transformer mixing, fold tokens back, then concatenate/project. Hybrid operation is repeated serially at several stages. | Designed for mobile use, with ImageNet-pretrained weights. Input-size/configuration differences and device kernels affect MACs and latency. | Direct pretrained hybrid baseline. Its existence rules out novelty claims for hybrid crack classification generally. It differs from CrackFusion's parallel post-stem paths and one late join. Verify exact input transform/count/latency. |
| **Mobile-Former** — Chen et al., CVPR 2022, [CVF paper](https://openaccess.thecvf.com/content/CVPR2022/html/Chen_Mobile-Former_Bridging_MobileNet_and_Transformer_CVPR_2022_paper.html), [arXiv](https://arxiv.org/abs/2108.05895) | MobileNet spatial stream runs beside a small set of learned latent tokens; cross-attention bridges image features to tokens and tokens back to feature maps. | Few latent tokens limit global path cost; repeated exchange adds projections/operations. Reported results are mobile/general-image benchmarks. | A small latent memory could reduce global compute if profiling shows need. It is not required solely because the project model is small. |
| **FastViT** — Vasu et al., ICCV 2023, [CVF paper](https://openaccess.thecvf.com/content/ICCV2023/html/Vasu_FastViT_A_Fast_Hybrid_Vision_Transformer_Using_Structural_Reparameterization_ICCV_2023_paper.html), [arXiv](https://arxiv.org/abs/2303.14189), [Apple code](https://github.com/apple/ml-fastvit) | Hierarchical hybrid uses RepMixer convolution/identity token mixing early and attention later. Training-time overparameterized branches are structurally reparameterized into a simpler inference graph. | Paper stresses memory movement and device-measured latency; ImageNet accuracy and speed are not crack evidence. | Benchmark actual target hardware; parameters and FLOPs do not determine latency. Reparameterization is unnecessary absent a deployment objective. |
| **EfficientViT (CGA)** — Liu et al., CVPR 2023, [CVF paper](https://openaccess.thecvf.com/content/CVPR2023/html/Liu_EfficientViT_Memory_Efficient_Vision_Transformer_With_Cascaded_Group_Attention_CVPR_2023_paper.html), [arXiv](https://arxiv.org/abs/2305.07027), [Microsoft code](https://github.com/microsoft/Cream/tree/main/EfficientViT) | Sandwich block places memory-efficient MHSA between FFN layers; cascaded group attention splits channels among heads and progressively feeds attended information forward. Hierarchical stem/stages reduce token counts. | Addresses memory-bound reshape/elementwise/tensor-movement costs beyond MACs; speed claims depend on hardware/runtime. | Profile current 196-token attention before replacing it. The general lesson is that FLOPs/parameter count can miss memory bottlenecks. |
| **MobileNetV4** — Qin et al., ECCV 2024, [ECCV paper PDF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/05647.pdf), [arXiv](https://arxiv.org/abs/2404.10518), [official implementation](https://github.com/tensorflow/models/tree/master/official/vision/modeling/backbones) | Universal Inverted Bottleneck unifies inverted bottleneck, ConvNeXt-like, FFN-like and extra-depthwise blocks; Mobile MQA adds attention in hybrid variants, with blocks chosen in a searched stage layout. | Hardware-aware NAS and accelerator-specific measurements; distillation/pretraining influence reported performance. | Contemporary mobile comparator/design reference. Fair comparison needs matched input, initialization and device methodology. |
| **SHViT** — Yun & Ro, CVPR 2024, [CVF proceedings](https://openaccess.thecvf.com/content/CVPR2024/html/Yun_SHViT_Single-Head_Vision_Transformer_with_Memory_Efficient_Macro_Design_CVPR_2024_paper.html), [arXiv](https://arxiv.org/abs/2401.16456) | Larger-stride stem reduces early token redundancy; early attention can be replaced by convolution, with a single later attention head combining local/global information. Hierarchical ViT, not separate persistent branches. | Optimized for memory and mobile/GPU/CPU latency; ImageNet speed/accuracy are not task evidence. | Supports testing if early attention or multiple heads add value. Current attention is small; use ablations rather than importing a new macro design by default. |
| **iFormer** — Zheng et al., ICLR 2025, [ICLR paper list](https://iclr.cc/virtual/2025/papers.html?layout=mini), [arXiv](https://arxiv.org/abs/2501.15369), [official code](https://github.com/ChuanyangZheng/iFormer) | Mobile hybrid family combines convolutional local representation and global self-attention with stage/operator choices tuned for mobile use. | Latency–accuracy tradeoffs are hardware and recipe dependent; ImageNet remains general-vision evidence. | Recent precedent means novelty rests on compact task-specific evaluation and controlled conclusions, not hybridization alone. |

## Synthesis: what transfers

1. **Convolution supplies local bias cheaply.** ResNet, CvT, CMT, MobileViT and MobileNetV4 all encode locality through convolutions, overlap, or depthwise mixing. Edges and texture continuity are plausible crack cues; this is motivation, not evidence that CNNs will outperform on SDNET.
2. **Attention is most affordable after spatial reduction.** ViT uses all-pairs interaction; Swin localizes windows; CoAtNet delays attention; CvT/CMT/MobileViT tokenize hierarchical CNN features. CrackFusion's 196 tokens are a reasonable tractable scale, so novel efficient-attention machinery needs measured justification.
3. **Fusion layout is a real variable, not a new idea by itself.** Conformer and Mobile-Former exchange information repeatedly; MobileViT mixes serially inside repeated blocks; CoAtNet/CMT interleave operators by stage; CrackFusion has parallel post-stem paths and one join. Compare topology with controlled ablations; do not imply general hybrid or parallel fusion novelty.
4. **Latency is not a parameter count.** FastViT, EfficientViT, MobileNetV4, SHViT and TinyNeXt show that memory movement, operator support, hardware and runtime matter. Report device, runtime, batch, resolution, warm-up, memory and measured latency with parameters/MACs.
5. **Initialization and independent sample size matter.** ViT's strongest origin evidence involved large-scale pretraining; DeiT improves training with extensive augmentation and optional teacher transfer; mobile hybrids often supply ImageNet weights. SDNET has 56,092 crops from 230 source images, so crop count is not the independent sample count. Group by source photograph and repeat seeds.

## Implications for the paper

- Use pretrained ResNet-18 as a recognized CNN reference and MobileViT-XS as the established pretrained hybrid. Label these as practical transfer comparisons; they do not isolate architecture against a from-scratch CrackFusion model.
- For the architectural claim, compare local-only, attention-only, and fused variants under a shared protocol and approximately matched parameter budgets where practical. Keep input, split, augmentations, and training budget aligned; disclose initialization differences.
- Retain the current 14×14 attention map unless experiments show the second block or 4-head attention is wasteful. A branch-removal/block-removal ablation is more informative than adding custom attention.
- Keep local and global branch outputs for attribution/error inspection. Attention visualizations and Grad-CAM are diagnostics, not causal proof.
- Use source-photo-separated splits and held-out surface evaluation; report recall/F1 and balanced metrics, repeated-seed variation, per-surface results, parameters/MACs, memory and measured latency. No ImageNet score in the architecture papers establishes crack accuracy.
- The defensible contribution is a compact explicit local/global layout tested under leak-resistant crack classification, not the invention of CNN–Transformer combination, parallel branches, or feature fusion.
